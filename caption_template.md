# Caption Template

```
{hook_line} 🧬

Scientists used to think {prior_consensus_short}.

But this new {journal} paper shows {why_conceptual_not_incremental_short}.

📌 Limitation: {limitations_short}

Source: {authors_short}, {journal} ({year})
DOI: {doi}

This account breaks down one Cell/Nature/Science-level paper every day.
Follow for more 👆

#science #research #{journal_hashtag} #{topic_hashtag} #biology #discovery #peerreviewed
```

## Rules
- The first line (hook_line) is what shows in-feed before "more" — this is what earns saves/shares, so it has to create curiosity without being clickbait.
- No overselling: never imply a conclusion the paper doesn't actually support (e.g. "cure," "breakthrough that changes everything") — this ties directly to the "no exaggeration" item in `templates/conceptual_advance_framework.md`.
- Keep hashtags to roughly 5-8; too many reads as spam. Mix journal name, subfield, and general science tags.
- DOI links aren't clickable in an Instagram caption — direct people to the profile link (Linktree etc.) if you want them to reach the paper.
- Always credit the authors and journal by name — required for CC-BY compliance and it also signals respect to the researchers, which can lead to real collaborations.
